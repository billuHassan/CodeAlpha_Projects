# Rahmour Fitness 🏃‍♂️

> **Rahmour Fitness** is a clean, modern activity and health dashboard built with vanilla HTML5, CSS3, and modern JavaScript.

---

## 🌟 Key Features

1. **Activity Rings Visualizer**: Interactive SVG circles for *Move (Calories)*, *Exercise (Active Minutes)*, and *Steps* tracking daily progress in real time.
2. **Weekly 7-Day Trend Chart**: Responsive SVG bar chart displaying weekly consistency and calorie outputs with today highlighted.
3. **MET-Based Calorie Calculation**: Automatic caloric estimation using Metabolic Equivalent of Task values across running, cycling, swimming, lifting, HIIT, yoga, and walking.
4. **Hydration Counter**: 1-click water logger (+250ml) tracking toward daily hydration goals.
5. **Interactive BMI Calculator**: Body Mass Index calculator with health classification and exercise guidance.
6. **Detailed Activity Log**: Filterable and searchable workout table with one-click deletion and automatic dashboard recalculation.
7. **CSV Export**: Export workout records directly to a `.csv` spreadsheet file.
8. **Streak Tracking**: Habits streak tracker keeping users motivated every day.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic tags, inline SVG graphics
- **CSS3**: CSS Grid, Flexbox, custom properties, responsive layout
- **JavaScript (ES6+)**: Modular state architecture, LocalStorage API, Blob API

---

## 🚀 How to Run

Open `index.html` in any web browser. No external dependencies or installations required.
