## 📌 Project Overview & Task Specifications

This application fulfills and exceeds all requirements defined under **TASK 2: Random Quote Generator**:

- ✅ **Automatic & Interactive Display**: Displays a meaningful random quote on initial page load and every time the user requests one.
- ✅ **"New Quote" Button**: Generates and transitions to a fresh, non-repeating quote on each click.
- ✅ **Clear Text and Author Presentation**: Displays the quote with high-contrast typography, attribution, and context bio.
- ✅ **Clean and Minimal UI**: Sleek, distraction-free interface emphasizing typography and readability.

---

## 🌟 Outstanding & Unique Features (Bonus)

1. **Category Filtering**: Filter quotes across *Tech & Code*, *Inspiration*, *Philosophy*, *Success*, and *Mindfulness*.
2. **Text-to-Speech (TTS) with Animated Audio Wave**: Reads the quote out loud using the browser's native Web Speech API, accompanied by a dynamic frequency-bar sound wave animation.
3. **HTML5 Canvas "Save as Image" Generator**: Converts any quote into a high-resolution 1080x1080 PNG graphic card with customized gradient backgrounds, typography, and quotes styling — ready for Instagram, LinkedIn, or Twitter!
4. **1-Click Copy & Multi-Channel Social Sharing**:
   - Copy quote & author directly to clipboard with instant toast alert.
   - 1-click share to Twitter/X, LinkedIn, WhatsApp, and Native Mobile Share.
5. **Favorites & Bookmarks Drawer**: Heart and save your favorite quotes into a persistent LocalStorage library.
6. **Dynamic Theme Switcher**: 5 curated visual color palettes:
   - 🌌 Cosmic Indigo (Default)
   - 🍃 Emerald Forest
   - 🌅 Sunset Rose
   - ⚡ Neon Cyber
   - 📜 Minimal Monochrome
7. **Auto-Play / Presentation Mode**: Automatic slideshow mode cycling inspiring quotes every 7 seconds.
8. **Add Custom Quotes**: Allows users to input and store their own quotes and authors locally.

## 🛠️ Tech Stack

## 🚀 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YourUsername/CodeAlpha_RandomQuoteGenerator.git
   cd CodeAlpha_RandomQuoteGenerator
   ```
2. **Open `index.html`** in any modern web browser or start a quick local server:
   ```bash
   python -m http.server 8080
   ```
3. Visit [http://localhost:8080](http://localhost:8080).
