# Rahmour Quotes ✨

> **Rahmour Quotes** is a clean, aesthetic random quote generator and wisdom reader built with vanilla HTML5, modern CSS3, and JavaScript.

---

## 🌟 Key Features

1. **Curated Categories**: Filter quotes across *Tech & Code*, *Inspiration*, *Philosophy*, *Success*, and *Mindfulness*.
2. **Text-to-Speech (TTS)**: Built-in natural audio readout with an animated frequency sound wave.
3. **Canvas Social Card Downloader**: Generates high-resolution 1080x1080 PNG graphics with gradient backdrops and typography for instant download.
4. **Favorites Library**: Bookmark quotes to a saved list stored in browser storage.
5. **5 Visual Themes**: Switch effortlessly between Cosmic Indigo, Emerald Forest, Sunset Rose, Neon Cyber, and Minimal Monochrome.
6. **1-Click Share & Copy**: Instantly copy formatted text to clipboard or share directly to social platforms.
7. **Custom Quotes**: Add and save your own quotes and authors in real time.
8. **Auto-Play Mode**: Hands-free slideshow cycling quotes every 7 seconds.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic elements, accessible Canvas 2D context
- **CSS3**: CSS Variables, animations, responsive design
- **JavaScript (ES6+)**: Web Speech API, Clipboard API, Canvas API, LocalStorage API

---

## 🚀 How to Run

Open `index.html` directly in your browser. No build steps needed.
