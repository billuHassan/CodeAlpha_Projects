# Rahmour Flashcards ⚡

> **Rahmour Flashcards** is a modern, high-performance flashcard study and quiz application built with vanilla HTML5, CSS3, and modern JavaScript.

---

## 🌟 Key Features

1. **3D Perspective Card Flip**: Realistic spatial animation with smooth flip transitions.
2. **Dual Learning Modes**:
   - **Study Mode**: Explore concepts at your own pace with text-to-speech audio.
   - **Quiz Challenge**: Timed knowledge check with instant assessment (*Mastered* vs *Need Practice*) and final accuracy report.
3. **Multi-Deck Management**: Pre-loaded decks for Web Development, Data Structures & Algorithms, and Spanish, plus the ability to create new custom decks.
4. **Full CRUD Customization**: Add, edit, search, and delete cards on the fly.
5. **Text-to-Speech (TTS)**: Built-in speech synthesis that reads questions and answers aloud.
6. **Deck Backup & Transfer**: Export complete decks as clean JSON or import decks across devices.
7. **Keyboard Shortcuts**:
   - `Space`: Flip card
   - `←` / `→`: Navigate between cards
   - `1` / `D`: Need Practice (in Quiz Mode)
   - `2` / `K`: Mastered (in Quiz Mode)
8. **Local Persistence**: Saves all cards, edits, and decks automatically in browser storage.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic tags, accessible layout
- **CSS3**: CSS Grid, Flexbox, 3D Transforms, Custom Properties
- **JavaScript (ES6+)**: Object-Oriented state engine, Web Speech API, LocalStorage API, File API

---

## 🚀 How to Run

Simply open `index.html` in any web browser. No build steps or installations needed.
