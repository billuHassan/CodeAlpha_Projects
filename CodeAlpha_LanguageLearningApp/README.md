# Rahmour Languages 🌍

> **Rahmour Languages** is an interactive multi-language learning platform and practice testing application built with vanilla HTML5, modern CSS3, and JavaScript.

---

## 🌟 Key Features

1. **4 Supported Languages**: Spanish (🇪🇸), French (🇫🇷), German (🇩🇪), and Japanese (🇯🇵).
2. **Native Speech Synthesis**: Accent-accurate audio pronunciation with a Slow Audio toggle (0.65x) for beginners.
3. **Triple Quiz System**:
   - **Multiple Choice Quiz**: Rapid 4-option challenge with instant feedback and XP rewards.
   - **Word Match Game**: Interactive dual-column pairing linking foreign terms to English meanings.
   - **Audio Listening Comprehension**: Auditory test where you listen to pronunciation before answering.
4. **Gamification Engine**: XP points system, level progression (Level 1 to Level 5+), daily streak tracking, and unlockable achievement badges.
5. **Word Bank & Audio Dictionary**: Complete vocabulary index with instant search and 1-click audio playback.
6. **Local Storage Persistence**: Progress, level, streak, and unlocked badges persist across sessions.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic tags, accessible layout
- **CSS3**: CSS Grid, Flexbox, custom properties, responsive design
- **JavaScript (ES6+)**: OOP Architecture, Web Speech API (`SpeechSynthesisUtterance`), LocalStorage API

---

## 🚀 How to Run

Open `index.html` in any modern web browser. No external installations or build tools required.
