## 📱 Repository Overview & Architecture

This repository (`CodeAlpha_AppDevelopment`) contains production-grade implementations of **all 4 tasks** assigned during the CodeAlpha internship. Each project is modular, fully accessible, responsive, and runnable with zero external build step requirements:

| Task | Project / Module Name | Folder | Description & Key Innovations |
| :--- | :--- | :--- | :--- |
| **Task 1** | **BrainSpark Flashcards** | [`./CodeAlpha_FlashcardQuizApp`](./CodeAlpha_FlashcardQuizApp) | 3D perspective card flip animation, Study & Timed Quiz modes, Web Speech API audio pronunciation, full CRUD card editor, JSON deck backup/import. |
| **Task 2** | **AuraQuotes** | [`./CodeAlpha_RandomQuoteGenerator`](./CodeAlpha_RandomQuoteGenerator) | Minimalist typography generator, topic filtering (Tech, Philosophy...), HTML5 Canvas 1080x1080 PNG image downloader, 5 dynamic themes, Web Speech audio. |
| **Task 3** | **PulseFit Pro** | [`./CodeAlpha_FitnessTrackerApp`](./CodeAlpha_FitnessTrackerApp) | Apple-Fitness-style 3-Ring SVG visualizer, MET-based automatic calorie calculation, 7-Day SVG weekly bar chart, hydration counter, BMI calculator, CSV export. |
| **Task 4** | **LinguaVibe** | [`./CodeAlpha_LanguageLearningApp`](./CodeAlpha_LanguageLearningApp) | Multi-language learning (Spanish, French, German, Japanese), native localized accent audio, 3 practice test formats (MCQ, Pairs, Audio), Duolingo-style XP & Badges. |
