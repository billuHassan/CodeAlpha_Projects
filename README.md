# CodeAlpha_AppDevelopment 🚀

> **Rahmour App Suite**  
> A collection of modern, responsive, and interactive web applications built with vanilla HTML5, CSS3, and modern JavaScript.

---

## 📱 Applications in the Suite

| Application | Module Folder | Key Capabilities |

| **Rahmour Flashcards** | [`./CodeAlpha_FlashcardQuizApp`](./CodeAlpha_FlashcardQuizApp) | 3D perspective card flip, Study & Timed Quiz modes, Web Speech API audio pronunciation, custom deck creator, full CRUD card editor, JSON deck backup/import. |

## 🛠️ Tech Stack & Architecture

- **Zero Build Dependencies**: Every application is standalone vanilla HTML5/CSS3/ES6+, ensuring instantaneous startup and 100% browser compatibility.
- **Web APIs Utilized**:
  - Web Speech API (`speechSynthesis`, `SpeechSynthesisUtterance`)
  - HTML5 Canvas 2D Rendering Context
  - LocalStorage API for state and preference persistence
  - Clipboard API for 1-click text copying
  - Web Share API for native mobile sharing
  - Blob & URL API for CSV and JSON data export
